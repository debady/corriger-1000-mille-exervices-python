----------------------------C'EST QUOI LA PROGRAMMATION ?----------------------------	
La programmation informatique, également connue sous le nom de codage, est l’ensemble des activités qui permettent l’écriture 
des programmes informatiques. C’est une étape importante du développement de logiciels. L’écriture d’un programme se fait dans un 
langage de programmation. Un logiciel est un ensemble de programmes destiné à la réalisation de certaines tâches par un ou plusieurs 
utilisateurs du logiciel. La programmation représente donc ici la rédaction du code source d’un logiciel. On utilise plutôt le terme pour 
dénoter l’ensemble des activités liées à la création d’un logiciel et des programmes qui le composent. Cela inclut la spécification du logiciel,
 sa conception, puis son implémentation proprement dite au
 sens de l’écriture des programmes dans un langage de programmation bien défini, ainsi que la vérification de sa correction, etc1

----------------------------POURQUOI FAIRE LA PROGRAMMATIOION ------------------
Il y a plusieurs raisons pour lesquelles vous pourriez vouloir apprendre la programmation. Voici quelques-unes des raisons les plus courantes:

Créer des applications: La programmation vous permet de créer des applications pour résoudre des problèmes ou pour divertir les gens. Vous pouvez créer
 des applications pour les ordinateurs de bureau, les appareils mobiles, les jeux vidéo, etc.

Améliorer votre employabilité: La programmation est une compétence très recherchée sur le marché du travail. En apprenant
 à programmer, vous pouvez améliorer vos perspectives d’emploi et augmenter votre salaire potentiel.

Comprendre la technologie: La programmation vous permet de mieux comprendre comment fonctionnent les ordinateurs et les 
logiciels. Cela peut vous aider à résoudre des problèmes informatiques et à utiliser les technologies plus efficacement.

Développer votre créativité: La programmation est un processus créatif qui vous permet de créer des choses nouvelles et 
intéressantes. 

Vous pouvez exprimer votre créativité en créant des applications, des jeux vidéo, des sites Web, etc.
Apprendre une nouvelle compétence: Apprendre à programmer est un défi stimulant qui peut vous aider à développer de nouvelles
 compétences et à améliorer votre capacité à résoudre des problèmes.

***********C’est quoi Python ?****************
Le langage de programmation Python a été créé en 1989 par Guido van Rossum, aux Pays-Bas. Le nom
Python vient d’un hommage à la série télévisée Monty Python’s Flying Circus dont G. van Rossum est
fan. La première version publique de ce langage a été publiée en 1991.
La dernière version de Python est la version 3. Plus précisément, la version 3.7 a été publiée en juin
2018. Ce cours est basé sur Python 3. La version 2 de de Python est désormais obsolète, dans la mesure
du possible évitez de l’utiliser.
La Python Software Foundation est l’association qui organise le développement de Python et anime la
communauté de développeurs et d’utilisateurs.
Ce langage de programmation présente de nombreuses caractéristiques intéressantes : - Il est multiplateforme. C’est-à-dire qu’il fonctionne
 sur de nombreux systèmes d’exploitation : Windows, Mac OS,
Linux, Android, iOS, depuis les mini-ordinateurs Raspberry Pi jusqu’aux supercalculateurs. - Il est
gratuit. Vous pouvez l’installer sur autant d’ordinateur que vous voulez. - C’est un langage de haut
niveau. Il demande relativement peu de connaissance sur le fonctionnement d’un ordinateur pour être
utilisé. - C’est un langage interprété. Le programme n’a pas besoin de compilé son programme pour
pouvoir l’utiliser, contrairement à des langages comme le C ou le C++. - Il est orienté objet. C’est-à-dire
qu’il est possible de créer en Python des entités qui ont un sens dans le monde réel (une cellule, une
protéine, un atome) avec un certains nombres de fonctionnement et d’interaction. - Il relativement
simple à prendre en main 12. - Enfin, il est très utilisé en bioinformatique et plus généralement en
analyse de données.
