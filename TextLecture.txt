Explications :

Nous utilisons la bibliothèque pyttsx3 pour la synthèse vocale.
pyttsx3 est une bibliothèque de conversion texte-parole en Python. Elle fonctionne hors ligne et est 
compatible avec les versions Python 2 et 3 et plus . Une fois installée, vous pouvez l’utiliser pour créer des applications de synthèse vocale.

Lorsque l’utilisateur clique sur le bouton “Saisir du texte”, une boîte de dialogue de saisie s’affiche.
Le texte saisi est affiché dans la console et lu à haute voix par le moteur de synthèse vocale.

 CAS OU VOUS AVEZ TOUJOURS DES DIFFICULTES
 --------------------------------------------------------

 
Vérifiez que Python est correctement installé :
Assurez-vous que Python est installé sur votre système. Vous pouvez vérifier cela en ouvrant une invite de commande
 (ou terminal) et en tapant python --version. Si Python est installé, vous verrez la version affichée. Sinon, vous devrez installer Python.
Ajoutez Python au PATH :
Si Python est installé, mais que vous obtenez toujours l’erreur, il est possible que le chemin d’accès à Python 
ne soit pas correctement configuré. Pour résoudre cela, vous pouvez ajouter Python au PATH système :
Sur Windows :

Allez dans les propriétés système (clic droit sur “Ce PC” ou “Ordinateur”, puis sélectionnez “Propriétés”).
Cliquez sur “Paramètres système avancés”.
Dans l’onglet “Avancé”, cliquez sur “Variables d’environnement”.
Sous “Variables système”, recherchez la variable “Path” et cliquez sur “Modifier”.
Ajoutez le chemin d’accès au dossier contenant l’exécutable Python (par exemple, C:\Python39\Scripts).

Enregistrez les modifications et redémarrez l’invite de commande.
Sur Linux ou macOS, le chemin d’accès à Python est généralement configuré automatiquement.
Utilisez la commande correcte :

Si vous avez correctement configuré Python, vous devriez pouvoir utiliser la commande pip. Assurez-vous de taper pip install 
pyttsx3 dans l’invite de commande (ou terminal) et non dans l’interpréteur Python.
Vérifiez l’orthographe :
Assurez-vous que vous avez correctement saisi la commande. Il doit s’agir de pip install pyttsx3, sans faute de frappe.
